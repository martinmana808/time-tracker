# The "How"

## Tech Stack
- Frontend: React 18
- Build Tool: Vite
- Language: TypeScript
- Styling: Tailwind CSS v4
- Icons: `lucide-react`
- State Management: `zustand`
- Utilities: `date-fns`, `clsx`, `tailwind-merge`

## Directory Structure
- `/src/components/` - Reusable UI components
- `/src/store/` - Zustand global state definitions
- `/src/types/` - TypeScript interface definitions
- `/docs/` - Master Logging Protocol documentation

## Coding Standards
- Use functional React components with Hooks.
- Prefer Tailwind utility classes for styling.
- Local storage must be synced seamlessly.
- Design must follow modern web aesthetics (vibrant colors, glassmorphism, dynamic animations).
