# Harvest Clone Timer Implementation Plan

The goal is to build a robust, premium-looking web application that works as a timer to track work on projects, similar to Harvest.

## Proposed Changes

### 1. App Scaffold
- **Stack**: React 18, Vite, TypeScript, Tailwind CSS.
- **Why**: Fast, modern, and perfectly suited for a client-side MVP without backend overhead.
- **Tools**: `lucide-react` for icons, `date-fns` for time formatting, `zustand` for state management, `clsx` and `tailwind-merge` for UI utility.

### 2. State Management
- We will use Zustand for simple, scalable, and reactive global state management hooked up to `localStorage` for persistence across reloads.
- **Models**:
  - `Project`: `{ id, name, color, createdAt }`
  - `TimeEntry`: `{ id, projectId, description, startTime, endTime, durationSeconds }`
  - `ActiveTimer`: `{ projectId, description, startTime }`

### 3. Core Features
- **Project Management**: A page to create, edit, and list projects.
- **Time Tracker**: A sticky or prominent stopwatch header/card where the user selects a project, types a description, and hits "Start".
- **Entry Log**: A list of chronological time entries that can be manually added or generated by the stopwatch.
- **Dashboard**: Aggregation of time spent per project, total for the day/week.

### 4. UI/UX Aesthetics
- Modern design interface (using modern web aesthetics).
- Premium features like soft shadows, dynamic hover states, and clear typography (Inter font).
- The user requires a "wow" factor at first glance.

# Walkthrough: Harvest Clone Timer

## Overview
We successfully built a frontend-focused, local-first Harvest clone using React, Vite, Tailwind CSS, and Zustand. The application allows users to create projects, track time against them, and evaluate basic time metrics in a dashboard.

## Completed Features
- **Project Structure**: Vite React app scaffolded with Tailwind CSS v4 and Lucide React.
- **State Management**: A fully persistent state created using `zustand` linked directly to `localStorage`, allowing project lists, timer data, and records to survive a browser refesh.
- **UI/UX**: 
  - An interactive sidebar-driven application with distinct views for Dashboard, Time, and Projects.
  - Premium design implementation with `inter` aesthetics, clean form elements (glassmorphism/subtle shadows), responsive spacing, and visual cues like border colors and hover states.
- **Projects Management**: Ability to create custom projects with names and identifying colors.
- **Time Tracker**:
  - Live ticking timer bound to `.startTime` state tracking.
  - Ability to start/stop working on a specific project.
  - Fast manual duration entry (e.g. logging 1 hour manually).
- **Dashboard**:
  - Automatically calculates total, today's, and this week's logged time via `date-fns`.
  - Aggegrates time per distinct project natively.

## Testing & Verification
The build was verified using the local Vite server (`npm run dev`). A systematic browser subagent test was enacted to:
1. Create a "My Test Project".
2. Switch to the Time tab and start a timer with the description "Writing Tests".
3. Wait 25 seconds and hit Stop.
4. Open the Dashboard tab and verify project aggregation features are pulling correctly.

Validation was fully positive, proving the robustness of the core React logic and `localStorage` synchronisation.
